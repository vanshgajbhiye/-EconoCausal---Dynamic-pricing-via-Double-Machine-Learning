# EconoCausal: Dynamic Pricing via Double Machine Learning

An end-to-end dynamic pricing platform powered by causal machine learning and modern web technologies.

## 📁 Repository Structure

```
d:/EconoCausal/
├── backend/          # Node.js + Express + MongoDB REST API
└── README.md
```

## 🚀 Backend Development

To start the backend development server:

```bash
cd backend
npm install
npm run dev
```

Visit the health check at [http://localhost:5000/api/health](http://localhost:5000/api/health).
For full backend documentation and endpoints, see [backend/README.md](file:///d:/EconoCausal/backend/README.md).
